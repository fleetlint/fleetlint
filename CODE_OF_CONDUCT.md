# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work, and do not harass anyone, in any channel connected to this project.

Reports go to the maintainers through the private channel described in `SECURITY.md`. Reports are handled confidentially; the maintainers decide on and communicate any consequences, up to a permanent ban from the project's spaces.
